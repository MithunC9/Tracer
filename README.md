# Tracer

A time-boxed audit of how you actually work. Install a small desktop app, let it observe your own work for 1–14 days, and get a report of which repeated tasks cost you the most time and how to fix each one.

> Tracer is only for observing your own work, on your own computer, with your consent. It must never be used to monitor another person.
